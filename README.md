# BOTANICA Real Estate Landing Page

A responsive landing page for the BOTANICA residential complex in Saint Petersburg, created as part of my frontend development practice.

🔗 [Live Demo](https://izzz1989.github.io/landing-one/)

## Technologies

- HTML5
- CSS3
- JavaScript
- Responsive Web Design

## Features

- Responsive layout for desktop and mobile devices
- Mobile navigation menu
- Property information sections
- Image gallery / slider
- Apartment offer sections
- Contact and viewing request form
- Location section
- Project documentation section
- Structured project files

## Project Structure

- `index.html` — page structure
- `css/` — styles and responsive layout
- `scripts/` — JavaScript functionality
- `images/` — images and visual assets
- `fonts/` — local fonts

## About

This project was created during my frontend development training to practice building a complete responsive landing page from a design layout using HTML, CSS and JavaScript.

The project focuses on page structure, responsive design, content presentation and interactive interface elements.
